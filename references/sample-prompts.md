# 常见资产类型的 Prompt 模板

这些是按 `prompting.md` 里的结构化骨架写好的示例，按实际项目替换主体/色彩/氛围等字段，不要照抄字面内容(除非碰巧就是同一个需求)。

## 首页 / 落地页 Hero 图

用途通常是宽幅横图，要给标题文案留出安全区，风格要能撑起"第一眼印象"。

```
用途: 首页 hero 区域背景图，页面加载后第一眼看到的内容，需要给左侧或上方的标题文案留出干净的负空间
主体: <产品/场景主体>
风格/媒介: 简洁的产品摄影质感 / 扁平插画(按项目调性二选一)
构图: 宽幅构图，主体偏右或偏下，右上/左侧留出大片纯色或渐变负空间供文案叠加
色彩: 贴合项目主题色 <具体色值>，背景色调柔和不抢主体
氛围/光线: 明亮、专业、有科技感(或按项目实际调性替换)
文字: 无
约束: 不要出现真实品牌 logo，不要水印，不要过于杂乱的背景细节
```

## 功能图标 / 小插画

用途是配合某个功能点或卡片使用，尺寸小，要在缩小后依然清晰可辨。

```
用途: 功能卡片配图，在页面里以较小尺寸展示(比如 200x200 左右)，需要在小尺寸下依然主体清晰
主体: <代表这个功能的核心意象，比如"一个对话气泡""一份文档加放大镜">
风格/媒介: 扁平插画风格，简化的几何形状，避免过多细节
构图: 主体居中，四周留白，方形或接近方形的构图
色彩: 贴合项目主题色 <具体色值>，2-3 种主色即可，不要过多颜色
氛围/光线: 干净、克制
文字: 无
约束: 不要阴影过重，不要写实风格(跟扁平插画混搭会显得不统一)
```

## 文章 / 博客配图

用途是穿插在长文本里，起到视觉调节作用，不需要承载太多信息密度。

```
用途: 文章正文中的配图，穿插在大段文字之间起视觉调节作用
主体: <呼应这段文字内容的场景或意象>
风格/媒介: <按文章调性定，比如"轻松的漫画风格"或"写实摄影">
构图: 横向构图，适合内文宽度，不需要为文案留白
色彩: 不强制贴合主题色，但要跟文章其他配图风格统一
氛围/光线: <按内容基调>
文字: 无
约束: 不要出现跟本文无关的具体品牌/人物/地标
```

## 空状态插画(列表为空、搜索无结果等)

用途是在功能性场景里缓和"什么都没有"的挫败感，通常需要轻松、不严肃。

```
用途: 空状态提示插画，出现在列表/搜索结果为空时，需要传达"轻松、不是出错了"的情绪
主体: <跟空状态语境相关的意象，比如"一个人在放大镜里找东西却找不到">
风格/媒介: 简单线条插画或扁平插画，色彩不要过多
构图: 居中构图，周围留白多，整体偏小巧
色彩: 贴合项目主题色，但饱和度可以降低，营造轻松感
氛围/光线: 轻松、略带幽默，不要传达"出错/失败"的负面情绪
文字: 无
约束: 不要出现警告/错误相关的视觉符号(红色叉号、感叹号等)
```

---

需要的资产类型不在上面这几种里也没关系，照 `prompting.md` 的骨架现场组织就行，这几个只是常见场景的起点，不是穷举。
